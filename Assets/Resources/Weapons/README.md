# Editable fly lance

Edit `Fly Lance Source.blend` in Blender. The model uses **Blender −Y toward the tip**, which imports as Unity +Z, and contains separate shaft, handle, hand guard, ferrule, and tip objects.

Unity rebuilds `Fly Lance.prefab` when the Blender source is newer. To rebuild it manually, use **Fruit Fly > Combat > Rebuild Editable Lance Prefab**. Runtime code can load the Blender source directly while the prefab is waiting to be rebuilt.
